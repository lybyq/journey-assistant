# 自驾规划：自驾路线与车辆费用

入口：`travel-driving/driving.service.ts`；界面：`DrivingPanel.vue`；地图：`RouteMap.vue`。

## 调用链

GCJ-02出发/到达/途经点 → 高德真实驾车路线 → 米/分钟归一 → 车辆数与能源消耗计算 → 费用集合 → 行程版本按日驾驶上限拆段安排。

## 学习重点

- 燃油/电耗公式均为 `米数 × 百公里消耗 × 单价 ÷ 100000`；消耗文本先转整数分数，金额使用 bigint，不让模型心算。
- 单价来源由用户明确提供，不能把人工估算伪装为实时油价。过路费、停车、租车、保险未知时保持未知；确认自有车辆无租金可明确填0。
- 车辆总费先乘车辆数。任一必要费用未知，人均完整费用保持空值。
- 真实驾驶、休息和充电分别计时；初排只拆真实总驾驶时长，具体停靠点需导航核实，未能排下的时长明确写入假设。
- 地图有实际折线才画实线路径；只有点位时显示虚线位置示意，不能宣称为实际导航。

接口 `POST /trips/:id/driving`，正文 `{ revision, input }`。长查询可取消，HTTP断开传播至MCP实际连接；失败不保存半条路线。

用100公里、百公里8升、8元/升验算64元；两辆车为128元能源费。测试还覆盖两车总费、未知过路费、休息与底层网络取消。
