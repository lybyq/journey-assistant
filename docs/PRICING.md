# 预算计算：确定性预算与价格对比

先读 `travel-pricing.ts`，再读 `travel-pricing/pricing.service.ts`、`quote.service.ts`，最后看 `PricingPanel.vue`。

## 计算流程

显式选中费用 → 检查ID/口径 → 排除包价包含项 → 单价最小单位 × 数量 → 有效汇率分数换算 → 已知小计 → 基点预备金 → 整数人数分摊。

人民币等币种的最小单位是分，日元是整数元；不能统一乘100。bigint完成中间运算，转number之前检查上限。分摊余数分给前几位，保证分摊和严格等于含预备金金额。

## 四种价格性质

| 性质       | 含义                 | 比较限制                           |
| ---------- | -------------------- | ---------------------------------- |
| live_quote | 授权供应商的短时报价 | 有效期、全部强制费用和条件必须核对 |
| advertised | 网页宣传/起价        | 不参与可订价格排名                 |
| estimate   | 明确说明假设的估算   | 只能作同口径估算比较               |
| unknown    | 尚未取得金额         | 显示已知小计，不能补为0            |

人工输入不能改成供应商身份。现有报价ID只允许切换 `selected`；改变金额必须新增报价，旧版本冻结原始值。重复 `scopeKey`、多包价覆盖冲突有明确排除原因，不偷偷重复累计。

报价条件包括日期、人数、间数、晚数与住宿标准；汇率有来源、查询时间和有效期。缺少核心费用分类、儿童政策或团条款时，行程不能以完整总价参与排名。当前比较展示费用、活动时长和问题，不宣称全网最低或自动判定最舒适。

接口：`GET/PUT /trips/:id/pricing`、`POST /pricing/items`。自动化覆盖分摊、汇率、日元、广告/过期报价、未知价、包价与人工身份边界。
