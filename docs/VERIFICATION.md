# 验证记录

本记录对应 2026-10-29 本地验收。自动化测试使用独立 PostgreSQL 数据库、Redis 随机命名空间和受控供应商协议服务；真实模型与高德验收使用专门的本地测试账户。

## 工程检查

执行 `pnpm check`，依次验证全项目 Prettier 格式、共享契约与前后端 TypeScript、自动化测试和生产构建。共 13 个测试文件、109 个测试，覆盖身份归属、流式恢复、工具安全、模型预算、供应商协议、预算与行程验证、版本、分享和导出等链路。

预算回归包括：工具 Schema 首轮精简与按需加载、临近上限时禁用后续工具并生成总结、已完成回答超出累计阈值仍保留正文，以及 SDK 不同 usage 元数据形式的真实用量统计。旧数据库对注释清理的兼容仅接受指定文件的已知前后摘要，未知 SQL 校验和仍拒绝启动，账本不被改写。

## 验证边界

航班、酒店与授权旅行团网关有真实适配器和协议测试；生产可订库存、最终含税价格、儿童住客条件及退改条款仍需对应供应商授权与实际确认。测试协议返回值、人工估算、搜索起价不能当作生产报价。
