# 自驾规划：自驾路线与车辆费用

入口：`travel-driving/driving.service.ts`；供应商：`amap-driving.client.ts`；归一：`driving-candidates.ts`；界面：`DrivingPanel.vue`和`domestic/DrivingComparisonTable.vue`；地图：`RouteMap.vue`。

## 调用链

GCJ-02出发/到达 → 高德Web服务推荐32/少收费36/速度38策略 → 保留供应商实际备选并去重 → 米/分钟/分归一 → 车辆数与能源消耗计算 → 同一比较组的路线及费用 → 选择某条路线的费用 → 行程按日驾驶上限拆段。

配置优先使用`AMAP_WEB_SERVICE_API_KEY`，未提供时尝试现有`AMAP_MAPS_API_KEY`，密钥只留在后端。Web查询全部失败才回退高德MCP，部分失败保留其余真实路线并提示。途经点仍走逐段查询，尚不支持全程多策略联合优化；当前比较为单程，往返、市内接驳与停车需要另算。

## 学习重点

- 燃油/电耗公式均为 `米数 × 百公里消耗 × 单价 ÷ 100000`；消耗文本先转整数分数，金额使用 bigint，不让模型心算。
- 单价来源由用户明确提供，不能把人工估算伪装为实时油价。收费从`path.cost.tolls`读取元并转分，兼容旧字段`path.tolls`；明确0元与缺字段分别处理。用户手填收费时标为人工假设。停车、租车、保险未知时保持未知；确认自有车辆无租金可明确填0。
- 车辆总费先乘车辆数。任一必要费用未知，人均完整费用保持空值。
- 真实驾驶、休息和充电分别计时；初排只拆真实总驾驶时长，具体停靠点需导航核实，未能排下的时长明确写入假设。
- 地图有实际折线才画实线路径；只有点位时显示虚线位置示意，不能宣称为实际导航。

接口 `POST /trips/:id/driving`，正文 `{ revision, input }`。长查询可取消，HTTP断开传播至供应商实际连接；失败不保存半条路线。每次比较保存独立`comparisonGroupId`，界面展示最新比较组，方案只引用选中路线的费用。`checkedAt`表示实际查询时间，收费为查询时估算，不承诺未来路况、节假日、ETC及各车型的实际结算金额。

用100公里、百公里8升、8元/升验算64元；两辆车为128元能源费。`tests/driving-comparison.test.ts`还覆盖策略参数、部分失败、真实路线去重、零收费与未知、取消、费用来源以及方案不能累加所有备选路线费用。真实查询记录见[验证记录](VERIFICATION.md)。
