# 工程底座与启动链路

工程底座负责工作区组织、编译顺序、环境校验、接口边界与页面容器。身份、实时对话和旅行领域服务使用同一套基础设施；整体职责见 [总体方案](ROADMAP.md)，当前验收见 [验证记录](VERIFICATION.md)。

## 从启动命令到可访问页面

1. 根目录 pnpm workspace 管理 API、Web 和共享契约，依赖版本由锁文件固定。
2. 先编译共享契约，再编译 NestJS；后端保留构造参数装饰器元数据，浏览器使用 Vue 与 Vite。
3. AppConfig 加载并校验后端环境；生产诊断开关、来源白名单、端口及存储秘密不合法时拒绝启动。
4. StorageService 连接本项目 PostgreSQL 与 Redis，迁移在互斥锁和事务中执行。迁移通过后 API 才监听端口。
5. Vue 读取健康状态并恢复登录身份；登录后按账户载入会话，实际问答进入认证 HTTP/SSE 通道。

## 关键入口

| 文件或目录                             | 职责                                        |
| -------------------------------------- | ------------------------------------------- |
| package.json                           | 启动、检查、构建与运维命令                  |
| packages/contracts/src                 | 前后端共用的严格 Zod 契约与 TypeScript 类型 |
| apps/api/src/bootstrap.ts              | Nest 装配、精确来源校验、统一错误与 OpenAPI |
| apps/api/src/config                    | 环境加载、配置合法性与生产约束              |
| apps/api/src/storage                   | 真实存储连接、迁移完整性、事务和就绪检查    |
| apps/web/src/pages/WorkspacePage.vue   | 导航、聊天、旅行方案与执行记录的组合        |
| apps/web/src/features/chat/markdown.ts | Markdown 解析、代码高亮与 HTML 允许列表净化 |

## 诊断与真实业务

开发诊断 WebSocket 只执行白名单健康检查；生产环境强制关闭。网页默认问答使用真实 Agent，必须配置模型。未配置供应商时对应查询明确不可用；人工需求、资料、估算、版本与导出仍可使用。

健康探针只公开进程与脱敏状态，配置存在不等于连接成功。错误响应保留追踪标识，避免暴露底层堆栈、连接串和密钥。Markdown 拒绝脚本、事件属性、表单、嵌入内容和远程追踪图片。

## 日常验证

先启动独立存储，再执行 pnpm check，最后启动 pnpm dev。检查包含格式、类型、真实协议测试和生产构建。测试创建独立数据库及 Redis 命名空间；不清空开发数据，也不使用生产报价作为固定测试样本。
