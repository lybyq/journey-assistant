# 总体方案与真实业务链路

旅行助手支持自由行、自驾游和跟团游，连接需求澄清、证据检索、候选查询、确定性预算、行程版本与交付。具体源码入口见 [学习指南](LEARNING.md)，实际验证范围见 [验证记录](VERIFICATION.md)。

## 技术结构

- Node.js、NestJS 与 TypeScript 组织身份、接口、领域服务、工具适配与事务。
- Deep Agents、LangChain 和 LangGraph 执行模型工具循环、公开计划、只读研究任务与检查点持久化。
- MCP adapters 连接 12306、高德和 Tavily；授权 HTTP 适配器连接 Amadeus 与旅行团网关。
- Vue 3、Vite、Pinia 与 Vue Router 提供网页；共享契约和纯状态归约器可供未来小程序复用。
- PostgreSQL 保存用户、会话、事件、旅行项目、费用证据和不可变版本；Redis 承担限流、缓存与连接槽位。

## 从提问到回答

1. 登录身份确定用户，服务端重新检查会话归属、幂等标识与并发限制。
2. 用户消息和运行事件原子保存，服务端读取该用户已授权的历史、偏好及当前旅行项目。
3. Agent 首轮只公开基础工具和能力目录；复杂查询通过目录加载所需 Schema。
4. 模型选择工具，真实领域服务或 MCP 适配器执行；公开参数与结果经过统一脱敏。
5. 金额由整数预算服务计算；行程由独立约束验证器检查，缺失信息保持待确认。
6. 主模型组织最终正文，事件与回答同步持久化；SSE 按序号补发，网页安全解析 Markdown。

## 旅行工作区的职责与依赖

| 职责     | 读取什么                              | 产生什么                              | 关键边界                                           |
| -------- | ------------------------------------- | ------------------------------------- | -------------------------------------------------- |
| 需求澄清 | 文字、画像与表单                      | 归一化 TripRequest 与追问             | 不把未知人数、日期或预算填成事实                   |
| 资料证据 | 需求、Tavily Search/Extract、人工来源 | 有来源和查询时间的摘录                | 搜索页面不能成为系统指令，起价不等于可订报价       |
| 城际交通 | 日期、乘员、站码及供应商响应          | 铁路或航班候选与费用                  | 12306 查询受可售窗口限制，跨时区保留当地时间       |
| 自驾规划 | 坐标、车辆、能源条件与高德路线        | 距离、时间、能源费、休息与未知费用    | 不把未知过路费、停车费或充电条件视为零             |
| 住宿游玩 | 地点、入住条件、证据及授权酒店报价    | 地点与酒店候选、条款和对应费用        | 地点不代表库存；全程房价、房间数和住宿晚数区分处理 |
| 旅行团   | 授权网关或人工完整条款                | 团期、包含项、购物自费和逐日安排      | 缺少团期、强制费用与退改条件时继续待确认           |
| 预算比价 | 已选费用、币种、汇率与包含项          | 小计、预备金、人均和比较结果          | 使用整数最小货币单位，拒绝重复计费与不完整最低价   |
| 行程版本 | 需求、真实候选、费用快照与活动        | 初排、独立验证结果、不可变版本和差异  | 检查时间、地理、营业预约、乘员与预算约束           |
| 分享交付 | 固定版本与访问令牌                    | 可撤销分享、Markdown、中文 PDF 与地图 | 分享只读且固定版本，密钥和身份数据不进入导出       |

网页工作区与聊天业务工具调用相同领域服务。仓储统一校验资源归属和 revision 乐观锁；身份不能通过更换入口绕过。研究子代理只获得只读领域工具。

## 展示与运行保障

回答支持章节目录、表格、清单、代码高亮、复制和阅读密度切换；公开计划和工具参数/返回值可以展开。页面展示真实执行状态，隐藏推理不作为公开内容发送。

每轮运行传播同一个取消信号，主子代理共同统计模型和工具额度。供应商独立超时与熔断，实际调用连接在结束或取消后回收。数据库租约使中断运行进入明确终态；浏览器重连恢复消息和事件，不偷偷重跑外部工具。

交付包含 Docker/Nginx、CI、运行指标、限流审计、真实数据库备份恢复与保留预览脚本。公网域名、TLS、生产镜像构建及部署由实际部署验收确认。

## 供应商和平台边界

航班、酒店与旅行团生产库存需要实际授权。没有配置时明确不可用；人工估算、测试响应、搜索页面价格和生产报价分别标识。当前提供规划与查询，未实现代客预订、支付或签约。

客户端当前为 Vue Web。后续小程序需要单独实现登录、流式传输、路由、剪贴板、Markdown、地图与平台权限适配，不能假设普通网页可以直接编译成微信小程序。
