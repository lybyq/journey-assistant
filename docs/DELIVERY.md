# 分享与运维：可视化交付与上线保障

入口：`travel-delivery/`、`travel/travel-rate.guard.ts`；界面：`DeliveryPanel.vue`、`RouteMap.vue`、`SharedPlanPage.vue`；部署见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 交付流程

时间轴/地图读取固定版本 → Markdown/PDF读取同一费用和来源快照 → 创建限时分享 → 匿名仅访问指定版本 → 到期、撤销或归档立即失效。

分享秘密为32随机字节，数据库只存SHA-256摘要；URL fragment由页面读取后通过POST正文发送，页面立即清除fragment。刷新已清除的页面需重新打开原分享链接。分享是持有链接即可访问，请先核对备注中是否有自己不想公开的内容。账户、邮箱、其他会话、checkpoint和供应商Key不进入公开数据。

Markdown保留逐日安排、费用性质/数量/币种/条件、有效期、待确认问题和来源。PDF使用PDFKit与仓库内OFL授权中文字体，真实分页，不依赖系统字体或运行时下载。下载仍需要账户鉴权。

## 运行保障

- 所有旅行私有API鉴权、归属与按用户限流；昂贵查询每用户最多2个并发、5分钟30次，另有90秒操作期限。
- HTTP断开、用户取消和超时传至实际供应商；MCP工具调用使用独立连接，防止一个用户取消其他用户请求。
- 事务内记录项目修改/版本审计。操作指标只保存模块、状态、耗时和错误码；不保存提示词、秘密或整段网页。
- 当前用户可看24小时操作统计和模型tokens；没有账单单价时明确不提供货币成本，tokens估算与实测分别标注。
- 日志保留脚本默认dry-run；只清理90天前指标与过期/撤销30天的分享，不自动删除用户正文、版本或checkpoint。
- Docker/Nginx/SSE配置、真实pg_dump/pg_restore备份脚本、GitHub Actions检查均在仓库。基础设施交付不等于已经公网部署。

测试验证分享摘要/固定版本/撤销、跨用户拒绝、归档、PDF和指标。生产上线还须使用部署方的域名、TLS、受保护密钥和真实供应商账户做现场验收。
