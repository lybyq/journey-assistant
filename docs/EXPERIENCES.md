# 住宿游玩：住宿、门票与餐饮

入口：`travel-experiences/experience.service.ts`；契约：`travel-options.ts`；页面：`ExperiencePanel.vue`。

## 三条数据路径

1. 高德地点检索仅保存名称、地址、GCJ-02坐标。营业、价格、预约和无障碍信息仍是未知。
2. 人工核实录入开放窗口、闭园日、预约、儿童政策、早餐、取消条款与当前项目证据；另存候选，保留旧版本依据。
3. Amadeus 酒店列表 → 指定入住/离店日、1间住客配置报价 → 每间全程价 × 间数。不会再乘晚数。

## 为什么限制酒店查询

当前授权流程支持成人可平均分房的明确配置。带儿童或无法平均分房时，需要供应商确认每间住客、床型和加床政策，因此拒绝推断库存；可录入有真实住客条件的人工报价。多房价格按单房报价估算，多房库存不能从1间推断。未取得税费确认时禁止当作完整可订价格排名。

`available=false` 的产品不保留为可选报价。TEST环境明确标识非生产。没有供应商权限时不会用地图地点或网页起价填补酒店库存。

接口：`POST /trips/:id/experiences/places`、`/hotels`、`/manual`，正文 `{ revision, input }`。行程版本独立检查当天开放窗口、闭园、预约与轮椅要求；模型不能一句“合理”跳过检查。

协议测试核对酒店200美元全程价、房间数量和不重复乘晚数；领域测试覆盖开放与无障碍冲突。
